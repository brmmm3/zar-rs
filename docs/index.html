ZAR creates fast, verifiable archives with commit-based updates, data deduplication, and optional authenticated encryption. Search or mount archives without extracting them.

Built for durable archives

ZAR combines efficient storage with a history you can inspect, verify, and restore.

Fast compression

Compress independent data blocks in parallel with Zstandard for responsive archive creation and extraction.

Versioned commits

Add file updates as commits, inspect earlier states, and compact history when older versions are no longer needed.

Deduplicated data

Repeated blocks can be shared within an archive commit, reducing redundant storage for similar data.

Authenticated encryption

Protect archive data with modern authenticated encryption and password-based key derivation.

Integrity and recovery

Verify archive checksums and use recovery scans to identify intact data around damaged regions.

Careful extraction

Validate paths and constrain restoration to the selected destination rather than trusting archive entries blindly.

Search without extraction

Find text across archived files with path filters, regular expressions, and optional surrounding lines.

Read-only mounting

Browse archive contents as a virtual filesystem on Linux and Windows, including earlier commit states.

Streaming integrations

Create archives from readers and extract individual files to writers without buffering whole files.

Choose your interface

Use the same archive format from a terminal, desktop, application, or supported language runtime.

zarc — command line

Create, inspect, update, verify, and restore archives from scripts or a shell.

zarg — desktop manager

Browse archive contents and commits, search files, and restore selected versions with a graphical interface.

zarmount — virtual filesystem

Mount ZAR archives read-only with FUSE on Linux or ProjFS on Windows. Select the latest or an earlier commit.

zcopy — network copy

Transfer file trees between machines in compressed, optionally encrypted ZAR batches.

zarmcp — AI tools

Provide local MCP tools to inspect and manage archives with read-only and tool-allowlist modes.

Quick start

Install from a local checkout, then create and verify an archive. See the repository for packaged installers.

# Install zarc from a local checkout
cargo install --path zarlib-cli

# Create an archive and inspect it
zarc create backup.zar documents/ src/ notes.txt
zarc info -v backup.zar

# Add changes, verify, and restore
zarc add backup.zar documents/
zarc check backup.zar

# Search archived text without extracting
zarc grep backup.zar 'TODO|FIXME' --file-filter '*.txt' -B 1 -A 1

# Restore the archive
zarc extract backup.zar --output ./restored/

Adding files does not automatically remove deleted paths. Use zarc remove for entries you want to delete. For mounting, see the zarmount guide for FUSE or ProjFS prerequisites; keep an archive unchanged while it is mounted.
