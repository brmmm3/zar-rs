# Bundled KDE icons

The icons in this directory are selected from the KDE4 Crystal Diamond icon
theme, version 1.1, by Paolino (Paolo Campitelli; <https://www.paolocampitelli.com/>).
They were copied from the provided
`KDE4CrystalDiamondIcons_1.1_LGPL3.0` icon collection and are distributed under
the GNU Lesser General Public License, version 3.0. See
[COPYING.LGPL-3.0](./COPYING.LGPL-3.0).

The icons are embedded in zarg and used for toolbar/dialog actions and archive
entry types. The rest of the theme is not bundled.
